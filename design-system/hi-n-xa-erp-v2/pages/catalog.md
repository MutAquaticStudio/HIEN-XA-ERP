# Catalog page override

- Treat customer, supplier, product, warehouse, vehicle, and employee records as operational master data, not marketing cards.
- Search and status filters remain above the table. Search accepts Vietnamese input with or without diacritics.
- Desktop uses a compact table with an explicit open action. Mobile switches to labelled record cards without horizontal overflow.
- Detail pages keep read-only derived summaries visually distinct from source fields and use keyboard-operable hash tabs with named tab panels.
- Never add an edit shortcut that bypasses the existing server command, permission, audit, or optimistic-locking flow.
