# Dashboard page override

- Keep the page operational and dense: date range first, then role-scoped KPIs, then source-labelled charts, then top-products and attention lists.
- Every metric shows its source, date range, and unit. The visible fallback table is the authoritative accessibility companion for each chart.
- Use navy/blue for data and amber only for attention, pending, or cash-net emphasis. Do not use color without a visible label.
- Preserve the server read-model values and role projection. UI changes must not introduce client-side totals or alternate formulas.
- Empty dashboard states explain the selected range and stay compact so the next actionable surface remains visible on mobile.
