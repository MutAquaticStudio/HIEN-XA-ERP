## Environment configuration

- Configure secrets only in the Cloudflare dashboard/Workers Builds secret store.
- Required values include session secret, bootstrap/recovery secrets where enabled, VAPID keys if push is enabled, and integration-only staging secret.
- Never configure production secrets in GitHub variables used by public preview builds.
- Bind `DB`, `PRIVATE_FILES`, `NEXT_INC_CACHE_R2_BUCKET` and `BACKGROUND_QUEUE` separately per environment.

## Release flow

1. GitHub commit triggers Cloudflare Workers Builds in Cloudflare's Linux environment without Docker.
2. Upload/deploy only staging version.
3. Run typecheck, unit, Worker build, staging integration, authentication, RBAC, A/B isolation, IDOR and route smoke tests.
4. Review UAT evidence and unresolved P1s.
5. Explicitly authorize a production version promotion in a separate operation.

No release step may run `docker`, `docker compose`, image build/pull or Odoo Python.
